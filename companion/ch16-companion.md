## Track C — The Capstone Build, Current Buttons (per printed step)

1. **Open the orchestration view:** Antigravity IDE → **CMD+E** (Mac) / **CTRL+E** (Windows) → **Agent Manager** — the view where several agents run side by side and their deliverables collect in the **Artifacts** panel.
2. **Topology dial — three peer agents, no orchestrator:** **New Project** → paste the printed no-orchestrator project description (Sensing Agent, Decision Agent, Communication Agent, one shared task list, no central controller) into the **Project Description** field. The current build will not stop you from omitting a lead — the refusal happens in your text, not in a setting.
3. **Work dial:** paste the real task into the task description box and start the project. The three agents pick up work asynchronously.
4. **Observability dial:** watch the **Artifacts** panel and the shared task list as the agents work; click any agent's tile to inspect which sub-task it claimed and what it wrote back.
5. **Reuse dial:** save the Project **as a template** (Project settings → save as template) so the tissue unit can be lifted and reused without redesign.

## The "Is This Still True?" Lab — Fall 2026 Baseline

1. *"Can you run several agents in parallel as peers, without one agent directing the others?"* — Antigravity Agent Manager: yes, via parallel async agents in one project/workspace set. Claude Code: yes via agent teams (see the Chapter 10 companion for the current enablement flag); teammates are peers under a lead, so note the lead's role in your log.
2. *"If one agent fails mid-task, what happens to the others?"* — On current builds, parallel agents in both tools continue independently; unclaimed tasks stay on the shared list. Log the exact answer your build gives you, with the date.
3. **Current surfaces that support the Track C build:** Antigravity IDE Agent Manager (primary, no-code); Claude Code agent teams (terminal equivalent). Nothing else in this chapter expires — the six dimensions, the Tissue Test, and the robustness perturbations are printed and stable.

## Answer Key

1. **B** — A prompt is ephemeral — it lives only in a single conversation and disappears when it ends. A skill is a named, packaged, reusable capability that persists in your AI setup indefinitely and can be triggered on demand.

2. **A** — The four components are: (1) a name and trigger, (2) instructions (the standing prompt), (3) context (what the skill knows about your world), and (4) a defined output format. All four are required for consistently excellent results.

3. **C** — The recipe represents the standardized, documented process. Just as a great chef writes the recipe down and executes it the same way every night, a skill standardizes your best process so the AI executes it consistently — freeing your mental energy for harder problems.

4. **B** — Before writing any instructions, you should find the best example of the task you have ever produced, study what made it excellent, and use that as the quality benchmark the skill must meet every time.

5. **C** — Meta-prompting means using Claude to write your skill instructions for you. You describe the task, paste in your best example, and ask Claude to produce the full skill specification — name, instructions, context, and output format.

6. **B** — An API (Application Programming Interface) is how software communicates with other software. When a skill bridges your AI to an API, the AI can use external tools to act on the world — not just reason about it.

7. **C** — The process starts with reading the tool's developer documentation to understand its capability (what it does, inputs, outputs), then describing that capability to Claude and asking it to write the skill instructions. No coding required.

8. **B** — The three skill types to build first are: the task you do most frequently (high-frequency), the task that produces the most value when done exceptionally well (high-value), and the task that is tedious but follows a repeatable pattern (tedious).

9. **C** — 30 minutes × 3 uses per week = 90 minutes saved per week. The chapter uses this math to illustrate how even a single skill quickly pays back its 30-minute build cost many times over.

10. **C** — A skill library converts your professional expertise into a system that runs consistently and at scale. Because it encodes your unique knowledge and standards, and because building it requires sustained deliberate effort, it is not easily visible or replicable by competitors.

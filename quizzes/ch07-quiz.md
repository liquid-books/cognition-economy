## Answer Key

| Q | Answer | Rationale |
|---|--------|-----------|
| 1 | B | Stateless means each conversation is a self-contained context window that is cleared when the session ends. The model itself is unchanged, but no session content persists to the next conversation. |
| 2 | C | A memory file is user-maintained — not platform-generated — deliberately composed and loaded at the start of sessions to provide standing context across multiple conversations. |
| 3 | B | Conversation memory exists only within a session (least persistent); file-based memory persists as a document between sessions; database memory persists permanently across all sessions (most persistent). |
| 4 | B | Memory is the standing brief that persists between sessions. Context is the task-specific material provided for the work at hand in a given session. They serve complementary roles; neither replaces the other. |
| 5 | C | Curation discipline is the active practice of deciding what to include, update, and remove — keeping the memory file current and focused on operational relevance rather than allowing it to accumulate everything that has ever been true. |
| 6 | B | Good curation means the file always reflects current reality. Completed projects should be archived or removed and shifting priorities updated. Retaining everything as historical record defeats the purpose of a concise, current brief. |
| 7 | C | Passwords, credentials, and highly sensitive personal information should never appear in a memory file. A memory file is a document that can potentially be seen by unintended parties; nothing whose exposure would cause harm belongs there. |
| 8 | C | The core problem is confusing memory with context. A memory file should be a concise foundation; detailed task-specific documents should be provided as session context when relevant. Overloading the memory file creates noise rather than signal. |
| 9 | B | Compounding value comes from iterative refinement. Each update makes the file a more accurate model of the user's current reality, so over months the AI's outputs are calibrated to a progressively richer and more accurate portrait of the user's context. |
| 10 | C | An over-long, poorly curated memory file degrades performance by filling the AI's attention with outdated and irrelevant content. The signal — current priorities and relationships — gets diluted by accumulated noise from completed projects and stale context. |

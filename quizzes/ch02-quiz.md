## Answer Key

| Q | Answer | Rationale |
|---|--------|-----------|
| 1 | B | A system prompt is standing instructions that load before every conversation — defining the AI's role, behavior, and job. It is not a question (A), a chat history (C), or a technical config file (D). |
| 2 | C | Meta-prompting is the process of having the AI interview you and then generate its own system prompt from your answers — not web search (A), tool evaluation (B), or prompt chaining (D). |
| 3 | B | An effective persona is a cognitive posture tied to a professional role — how the AI thinks and communicates. A name and backstory (A) are not functional. Topic restrictions (C) are rules, not persona. Model version (D) is irrelevant to persona design. |
| 4 | B | The four components are Role, Context, Rules, and Format. The other options mix in real concepts (tone, constraints) but are not the framework as defined in the chapter. |
| 5 | C | Antigravity means the configuration work is done once and lifts friction from every session that follows. It is not about auto-updating (A), performance (B), or bias reduction (D). |
| 6 | B | A persistent system prompt eliminates the re-briefing problem by loading the context automatically. Switching models (A) doesn't solve configuration absence. Manual pasting (C) is a workaround, not a solution. Voice input (D) is irrelevant to the issue. |
| 7 | B | The three-tool architecture works because each tool is calibrated for a specific job. Cost (A), data sharing (C), and vendor redundancy (D) are not the reasoning given in the chapter. |
| 8 | D | Format governs how output is structured — length, bullets vs. prose, headers. Role defines the AI's job (A); Context provides background (B); Rules govern inclusions/exclusions (C). |
| 9 | B | The interview dynamic is what makes meta-prompting powerful — it surfaces specific preferences the user wouldn't think to write down. It doesn't produce shorter prompts (A), cross-tool sync (C), or eliminate future updates (D). |
| 10 | C | Each tool has a different job, and each job's context has changed. All configurations should be updated independently. Starting over (A) is disproportionate. AI tools do not self-adapt (B). Updating only one tool (D) leaves the others miscalibrated. |
